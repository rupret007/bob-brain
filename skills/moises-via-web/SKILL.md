# Moises via web (no API)

Use when Jeff wants stems, chords, key, sections, or cleanup from Moises **without** Music.ai / Moises Jobs API spend.

## Law
- Prefer **browser Moises** (studio.moises.ai) over any paid API key.
- Never ask Jeff to paste API keys in chat.
- Never buy credits / upgrade plans without a separate Jeff yes.
- Output is Logic-ready: WAV/AIFF stems (and any chord/section notes) into his existing path — not Ableton-first.
- WebJam Song Tools Music AI key stays optional/off unless Jeff revisits spend.

## Efficient Bob method
1. Confirm which mix/file (path or Drive link). Prefer files already in Moises library — do not re-upload duplicates.
2. If Moises session expired: hand Jeff the box/Mac browser once (`request_box_help` / he signs in on his Mac). Session persists after that.
3. Drive Moises web (browserUse/computerUse): open the track → run stems / chords / sections as asked → download artifacts.
4. Stage downloads in a clear folder (Desktop or song take folder) with human names (`vocals.wav`, `drums.wav`, …).
5. Tell Jeff in 2–3 short bubbles: what ran, where the files are, Logic drop next. Offer to open Logic / place tracks only if he wants.

## Batching
- One login covers many songs.
- Queue multiple stem jobs in one Moises session when Jeff names a list.
- Skip Suno unless he asked for a finished-sounding pass and is signed in.

## Do not
- Use Music.ai Jobs API / `MUSIC_AI_API_KEY` for this path.
- Claim WebJam in-room Song Tools work without a key — point to this web flow instead.
- Auto-post or auto-spend.
