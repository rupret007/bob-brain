## Universal conductor rules (all models)
1. **One coding lease per checkout** — never dual-lease Cloud+Codex+Claude on the same tree.
2. **Evidence decides done** — tests, builds, screenshots, tip SHA; never “looks done.”
3. **Outcome → verify → constraints → boundaries → iteration → blocked stop** for long work (same six-part idea across stacks).
4. **Tighten vague goals** instead of spam CONTINUE / “keep going.”
5. **Ping Jeff only for real owner gates** (login, signing, spend raise, feel, physical).
6. **Anti-waste routing** — BYOK (MiniMax/Gemini API), Mac Mini Codex/Claude paste, and **LOCAL Cursor Composer** (`local_cursor`) before Cursor Cloud Background Agents; never default-spray Gemini through Cloud; do not conflate local Cursor with Cloud BA.
7. **Read real meters** before routing (usage pulse / dashboard) — never invent %.
8. **Heavy coder vs light conductor** — put weight on included coding pools; keep Grok Bot lean when tokens are tight.
9. **Smoke before trust** — after outages/login changes, run Level A (and Level B if Jeff asks) via the smoke-test skill.
10. **Absolute checkout in every Goal** — name the Mini path; after a Cloud PR lands, fetch that tip before Mini continues the same PR.
11. **Model chip must match the ask** — Extra High means Extra High (not Medium); Claude Sonnet on Pro unless Jeff opens paygo.
12. **Work-now visibility** — Jeff wants what each resource is working on (repo/PR/goal), not mere Running chips; Gemini and MiniMax must appear on the board.
