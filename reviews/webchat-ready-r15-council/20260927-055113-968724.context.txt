## Borrow

| Idea | Source | R15 use |
|------|--------|---------|
| Grok chat bar | `grokbot-ref-chatbar-0346.png` | `+` outside pill; mic + textarea + **waveform call inside pill**; hide desktop send on phone (Return sends) |
| Flat assistant text | Grok iOS | Assistant turns without heavy bubble chrome; typing row with avatar + dots |
| Computer icon → Jobs | Grok header | `#open-ops` jumps to Jobs tab (live cards, not handback dump) |
| Hold mic → clip | Jeff 03:44 (secondary) | MediaRecorder hold uploads via existing `/api/audio/upload` ($0) |
| Jobs tab clarity | Jeff 02:30 | Hide redundant `jobs-ops-detail` dl when live/queued cards already show state |
| Fail-closed drills | R11–R20 | Handback ×2 isolated; ready drill p50 |

## Reject

| Idea | Why |
|------|-----|
| Bottom sheet tabs | Jeff 02:30 — real fixed tab bar only |
| MiniMax music API | 410 / not entitled |
| Grok as worker | Standing rule |
| Status above chat | Violates 02:18 layout — header pill only |
| Full WebRTC call streaming tonight | L effort; keep existing live-call dialog + council defer |

1. **Voice (9.79)** — hold-to-talk clip + Grok call placement.
