**3. Walrus assignment bug is valid.**
```python
reverse_ok = "handback drill" in (log_path := ...).read_text(...) if log_path.exists()
```
`log_path` is referenced before assignment on the right side of `:=`. This is a Python 3.8+ semantic error — the walrus binds after the condition evaluates, causing `UnboundLocalError`.

**What to change:** Create or verify `ops_panel.py` with a bounded, cached snapshot and explicit source/age fields; fix the walrus to assign `log_path` first.
