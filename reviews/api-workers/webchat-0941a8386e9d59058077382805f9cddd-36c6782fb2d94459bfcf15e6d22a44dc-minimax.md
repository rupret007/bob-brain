### Concern: Missing Task Prompt Recording

The job state transition system in `services/state.py` (`job_event()`) persists all fields passed to it, but **nothing forces the original prompt to be stored**. If a dispatch worker fails before calling `job_event` with the prompt, or if the prompt is only held in memory during execution, it won't appear in `jobs.jsonl`.

**No regression test** in `services/test_api_workers.py` verifies that `task_queue.enqueue()` captures the full prompt. The fixture creates jobs but doesn't assert prompt preservation.
