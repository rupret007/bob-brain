### Findings

The core issue for task `1605` is ensuring that worker-generated reports, especially for tasks requiring an implementation or unblock plan, contain a structurally valid `Action plan:` section. This section must include `Change:`, `Validation:`, and `Exit condition:` fields with their values on the same line.

1.  **Existing Enforcement**: The module `services/result_acceptance.py` contains the function `check_deliverables`, which is responsible for this validation. It uses `plan_heading()` to determine if a plan is required based on keywords like "unblock" or "actionable plan" in the task prompt. If a plan is required, it checks for the presence and correct format of the `Change:`, `Validation:`, and `Exit condition:` fields. An `Action plan:` or `Unblock plan:` heading is mandatory. This check is performed before a report can be accepted.

2.  **Test Coverage**: The test file `services/test_action_plan.py` provides comprehensive coverage for this requirement.
    *   `ActionPlanTests.test_exact_f2c47_failure_and_missing_plan_cannot_win_a_positive_vote` confirms that an answer from `services/fixtures/texting_action_plan_1605.json` lacking the required plan is rejected by `result_acceptance.accept` before it can be sent for semantic review.
    *   `ActionPlanTests.test_outer_plan_is_required_for_each_heading_and_label` verifies that each of the three required fields (`Change`, `Validation`, `Exit condition`) must be present with a non-empty value on the same line as its label.
    *   `WorkerActionPlanTests.test_dispatch_all_workers_enforce_outer_plan_before_publication` confirms that the `dispatch_worker.execute` function correctly invokes this validation for all worker types and fails the task if the plan is missing, preventing the publication of a non-compliant report.

3.  **Implementation**: The current implementation correctly enforces the action plan requirement. The `dispatch_worker.execute` function calls `result_acceptance.check_answer`, which in turn calls `check_deliverables`. This gate is active for all workers.
